With a focus on quality and convenience, we bring the freshest goods directly to your doorstep, ensuring a delightful shopping experience every time!

## 🚀 Technologies Powering the Experience

Our platform is built using cutting-edge technologies to deliver a smooth and scalable user experience.

### Frontend
- **Node.js v18**: Speed and efficiency for modern web development.
- **npm v8.19.1**: Managing dependencies with ease.
- **Next.js**: The powerful framework that brings everything together with server-side rendering.

### Backend
- **C#** with **.NET 8**: Ensuring a robust and scalable server-side experience.
- **SQL**: Reliable data storage for fast, accurate retrieval.
- Middleware tools like **AutoMapper** and validation libraries to keep everything running smoothly.

## 🛠️ Backend Architecture – Built for Performance

Our backend is built on a solid foundation, designed for scalability, reliability, and flexibility.

- **CQRS Pattern**: Separates query and command functions to boost performance and maintainability.
- **AutoMapper**: Efficiently maps objects to DTOs, streamlining request/response handling and enhancing flexibility. 
  <p align="center">
    <img src="https://github.com/user-attachments/assets/dddc8f27-d553-45f9-a3ff-da97b4367471" alt="AutoMapper" width="800"/>
  </p>
- **JWT Authentication**: Ensures secure login and role-based access, with **RefreshToken** and **Revoke** functionality for a seamless and secure user experience.
